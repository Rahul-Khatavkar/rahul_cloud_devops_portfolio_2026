# Cloud & DevOps Portfolio
**LIVE HERE: https://rahulkhatavkarportfolio.vercel.app/**

Open `index.html` in a browser to view the site.

## Personalizing the portfolio

All editable copy and repeatable content is in `content.js`:

- Identity, availability, introduction, email and location
- Technology ticker and key metrics
- Projects and their tags
- Services and social links
- Career experience, work process, technical toolkit, and testimonial

Change the text inside that file, save, then refresh the browser. The layout builds the project, metric, service, and social sections automatically.

For a production site, replace the `#` social links in `content.js` with your public URLs and update the email address.
